常见问题

怎么在 Mac 上打开屏幕共享？
  1. 打开 系统设置 › 通用 › 共享（macOS 12 及更早版本是 系统偏好设置 › 共享）。
  2. 打开「屏幕共享」。
  3. 在远屏里选这台 Mac，输入 Mac 的用户名和登录密码；如果在屏幕共享选项里设了 VNC 密码，也可以只填这个密码。
怎么在 Windows 上打开远程桌面？
  1. 打开 设置 › 系统 › 远程桌面，打开「远程桌面」并确认。
  2. 在远屏里选这台电脑，输入 Windows 账户和密码；Microsoft 账户填邮箱。

远程桌面需要 Windows 专业版、企业版或教育版，家庭版没有这个功能。连上后，电脑本机的屏幕会锁上，在电脑前的人要重新登录。

不在家或不在公司，怎么连？

远屏本身不建立 VPN，在外面连回电脑要用你手机上已经装好的公司 VPN 或 Tailscale App：

  • 公司 VPN：iPad / iPhone 连上公司 VPN，就能按内网地址连办公室的电脑。可以在「设置 › 其他网络」里登记公司内网网段，连着 VPN 时远屏会优先走内网地址。
  • Tailscale：在电脑和 iPad / iPhone 上都装好 Tailscale App，登录同一个 tailnet。回到电脑列表，点一下 tailnet 里的电脑即可连接。想让 tailnet 里的电脑自动列出来，可以在「设置 › 网络接入 › Tailscale 设备列表」里填一个只读的 API 令牌。

iPhone / iPad 同时只能开一个 VPN：开了公司 VPN，Tailscale 就会断开。

不需要端口转发，也不用把电脑暴露在公网上。

App 提示“电脑在线，但没打开屏幕共享 / 远程桌面”

说明网络是通的，只是电脑上的开关没开。按上面的步骤在电脑上打开屏幕共享或远程桌面，再回到 App 重试，不用装任何东西。如果开关已经打开，检查电脑的防火墙是否拦住了这项服务。

有些快捷键按了没反应

少数组合键会被 iPadOS 自己拦下，比如 Command-Tab、Command-空格、Control-空格。会话工具栏里有这些快捷键的按钮，点一下就会发给电脑。

通过屏幕共享连 Mac 时，中文粘贴不过去

macOS 屏幕共享（VNC）的剪贴板只支持英文和符号，中文请在电脑上直接输入。使用 Remote Host 连接时没有这个限制。

一定要装 Remote Host 吗？

不用。屏幕共享和远程桌面已经能完整地远程控制电脑。Remote Host 是可选的，提供更好的画质、多显示器与虚拟屏、文件收发和观看模式等功能。

远屏会收集我的数据吗？

不会。连接直接从你的设备到你的电脑，不经过开发者的服务器；App 没有统计和崩溃上报。详见 隐私政策。
